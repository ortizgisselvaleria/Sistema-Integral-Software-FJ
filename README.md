# Sistema-Integral-Software-FJ
Sistema integral desarrollado en Python aplicando programación orientada a objetos.

# Descripción del proyecto

Sistema integral desarrollado en Python para la gestión de los procesos y servicios de Software FJ, aplicando los principios de la Programación Orientada a Objetos (POO).

# Objetivo general

Desarrollar una solución de software que permita gestionar las entidades y operaciones del sistema mediante una estructura organizada, reutilizable y segura.

# Conceptos de programación aplicados

Abstracción.

Herencia.

Polimorfismo.

Encapsulamiento.

Sobrecarga.

Manejo de excepciones personalizadas.

# Tecnologías

Python 3.

GitHub.

Programación Orientada a Objetos.

# Consideraciones técnicas

No se utilizarán bases de datos.

La información se gestionará mediante objetos y listas.

Los archivos se utilizarán exclusivamente para almacenar registros de eventos (logs).

Se implementarán pruebas de operaciones válidas e inválidas.

Se contemplarán al menos 10 operaciones para verificar el funcionamiento del sistema.

# Estructura del proyecto

La estructura de carpetas y archivos se definirá durante el desarrollo.

# Ejecución

Las instrucciones de instalación y ejecución se documentarán una vez implementado el sistema.
